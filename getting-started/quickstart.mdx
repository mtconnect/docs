The fastest way to get an MTConnect Agent running on Windows is to download the prebuilt binary. You'll have live XML data in under 5 minutes.

## 1. Download the Agent

Go to the [cppagent releases page](https://github.com/mtconnect/cppagent/releases) and download the latest Windows binary (`.zip` file) under **Assets**.

Unzip the archive — you'll see `agent.exe` and a default `agent.cfg` config file inside.

## 2. Start the Agent

Open a Command Prompt, navigate to the unzipped folder, and run:

```bash
agent.exe run agent.cfg
```

The agent starts with a built-in simulator device. Open your browser to verify:

```bash
curl http://localhost:5000/probe
```

Or just open `http://localhost:5000/probe` directly in your browser.

## 3. Your First Client (Python)

```python
import requests
import xml.etree.ElementTree as ET

BASE = "http://localhost:5000"

# Discover devices
probe = requests.get(f"{BASE}/probe")
root = ET.fromstring(probe.text)
print("Connected to MTConnect Agent")

# Read current values
current = requests.get(f"{BASE}/current")
print(current.text[:500])
```

## Alternative: Run with Docker

If you're comfortable with Docker, you can also spin up the agent in one command:

```bash
docker run -it --rm -p 5000:5000 \
  mtconnect/agent:latest
```
