The MTConnect Agent exposes every endpoint described in [Streams & Samples](/concepts/streams-and-samples) — `probe`, `current`, `sample`, and `asset` — through a self-documenting REST API. Every C++ Agent (v2.2+) serves its own Swagger specification at `/swagger`, and the pages in this section are generated directly from that specification.

<Info>
  This reference is generated from the live specification served by the public demo Agent at [demo.mtconnect.org/swagger](https://demo.mtconnect.org/swagger), running Agent version 2.7.0.13.
</Info>

## Try it live

Every endpoint below includes a **Try it** panel pre-configured against `https://demo.mtconnect.org/` — the public MTConnect demo Agent. You can send real requests and see real responses without installing anything.

<Tip>
  Prefer to hit your own Agent? Change the server value in each **Try it** panel to your Agent's base URL, for example `http://localhost:5000/`.
</Tip>

## Response format

All endpoints return **XML by default**. Add `format=json` as a query parameter, or send `Accept: application/json`, to receive the JSON representation instead:

```bash
curl "https://demo.mtconnect.org/current?format=json"
```

## Where this spec comes from

The C++ Agent has served its own Swagger UI at the `/swagger` path since **v2.2** (see the [changelog](/reference/changelog)). Because the specification is generated by the Agent itself, it always reflects the exact endpoints and parameters supported by whatever version you're running — the copy embedded in this site is a snapshot for documentation purposes and may lag behind your Agent's own `/swagger` page for pre-release or patch versions.
